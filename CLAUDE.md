## Agent skills

### Issue tracker

Issues live in GitHub Issues (`EHoffm/kapps_semantic_middleware`, via the `gh` CLI). External PRs are also pulled into the triage queue. See `docs/agents/issue-tracker.md`.

### Triage labels

All five canonical role names used as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout: `CONTEXT-MAP.md` at the root points to five contexts (Core Middleware, SHACL Interop, Example Scenarios, TransferUnit Factory, Module Requirements). See `docs/agents/domain.md`.
